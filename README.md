# 🚀 Min Personlige Portfolio

Dette er min moderne portefølje bygget med **Next.js 15**, **TypeScript** og **Tailwind CSS**. Siden fungerer som mitt digitale visittkort og viser frem prosjektene mine med fokus på ytelse og brukeropplevelse.

## 🔗 Se siden live
**[👉 namhoangvu-portfolio.vercel.app](namhoangvu-portfolio.vercel.app)**

---

## 🛠 Teknologi brukt

Jeg har valgt en moderne "tech stack" for å sikre at siden er lynrask og enkel å vedlikeholde:

* **Rammeverk:** [Next.js](https://nextjs.org/) (App Router)
* **Språk:** [TypeScript](https://www.typescriptlang.org/) for tryggere koding
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) med CSS-variabler
* **Animasjoner:** [Framer Motion](https://www.framer.com/motion/) for flytende overganger
* **Deployment:** [Vercel](https://vercel.com/) med automatisk CI/CD fra GitHub

---

## ✨ Funksjoner

* **Responsivt Design:** Optimalisert for alt fra små mobiler til store 4K-skjermer.
* **Mørkt Tema:** Moderne estetikk med "glassmorfisme" og bakgrunns-blurs.
* **Interaktive Prosjektkort:** Dynamisk visning av mine nyeste koding-prosjekter.
* **Bildeoptimalisering:** Bruker Next.js Image-komponenten for raskest mulig lastetid.

---

## 🚀 Hvordan kjøre prosjektet lokalt

Hvis du vil se på koden eller teste den på din egen maskin:

1.  **Klone repoet:**
    ```bash
    git clone [https://github.com/NamHoangVu/min-portfolio.git](https://github.com/NamHoangVu/min-portfolio.git)
    ```
2.  **Installer avhengigheter:**
    ```bash
    npm install
    ```
3.  **Start utviklingsserveren:**
    ```bash
    npm run dev
    ```
4.  Åpne [http://localhost:3000](http://localhost:3000) i nettleseren din.
